# アクティビティを見る

左メニューの **アクティビティ**（ダッシュボード）では、投稿状況の概要とエラーを確認できます。

![アクティビティ画面](/img/screenshots/activity.png)

## 表示される内容

- **統計カード** … 登録アカウント数や投稿の状況などの概要。
- **エラー一覧** … 直近の投稿エラーとその内容。

エラーが出ている場合は、内容を確認し、該当する投稿を「[投稿を管理する](./manage-posts.md)」のエラータブや予約タブで修正してください。予約し直すと、次回以降の自動投稿で再度投稿されます。

## アカウント管理・投稿画面への移動

アクティビティ画面のボタンや、左メニューの **SNS** ツリーから、各プラットフォームのアカウント管理・投稿画面に移動できます。
