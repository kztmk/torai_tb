# Autopost とは

**Autopost** は、**Threads** と **Bluesky** への投稿を作成・予約・自動投稿できる Web アプリです。複数アカウントへの同時投稿（クロスポスト）、スレッド連投、画像付き投稿、AI による下書き一括生成、投稿結果の Discord 通知などに対応しています。

投稿データはあなた自身の **Google スプレッドシート**（GAS バックエンド）に保存され、画像はあなたの **Google ドライブ**に保存されます。運営側にデータやコストが集中しない構成です。

## 対応プラットフォーム

| プラットフォーム | 認証方式 | 文字数の数え方 |
| --- | --- | --- |
| **Threads** | Meta の OAuth 認可 | 文字数（コードポイント） |
| **Bluesky** | ハンドル + App Password | 書記素（grapheme） |

## 全体の流れ

1. **アカウント作成・サインイン** — メールアドレスで登録します。
2. **GAS 連携** — あなたの Google スプレッドシートをバックエンドとして接続します。
3. **API 設定** — 必要に応じて AI キー・Discord Webhook を登録します。
4. **SNS アカウント連携** — Bluesky / Threads のアカウントを登録します。
5. **投稿の作成** — 本文・画像・予約日時を設定して投稿を作ります。
6. **投稿の管理** — 一覧で編集・並び替え・投稿間隔の配分を行います。
7. **自動投稿を ON** — ヘッダの時計アイコンから自動投稿を稼働させます。
8. **結果の確認** — アクティビティ画面や Discord 通知で結果を確認します。

:::tip 画面の言語
右上の言語切替、およびアプリ本体は **日本語 / 英語** に対応しています。このマニュアルも右上のドロップダウンから英語に切り替えられます。
:::
