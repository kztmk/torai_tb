# よくある質問・トラブルシューティング

### Q. 予約したのに投稿されません

次を確認してください。

- **自動投稿が ON になっているか** … ヘッダの時計アイコンが緑色（ON）か確認します。
- **予約日時が設定されているか** … 予約日時が空の投稿は「予約なし」となり自動投稿されません。
- **予約日時が過去 / 未来か** … 予約時刻が到来していない投稿は、その時刻まで待機します。
- **GAS が最新版でデプロイされているか** … バックエンドが古いと自動投稿やトリガーが動作しないことがあります。

### Q. 「アクセス権限がありません」と表示されます

スプレッドシートの **「Autopost 連携」メニュー**から権限の再承認をやり直してください。それでも解決しない場合は、Google Sheets URL と本人確認コードを設定し直してください。

### Q. 本人確認コードが無効と言われます

本人確認コードには有効期限（生成から約 10 分）があります。スプレッドシートの **「Autopost 連携」→「セットアップ（デプロイ手順）」**を再実行して新しいコードを生成し、入力し直してください（すでにデプロイ済みなら、デプロイ手順は飛ばして新しいコードだけ貼り直せば OK です）。

### Q. デプロイのとき「ウェブアプリ」が選べません／URL が出ません

「デプロイ → 新しいデプロイ」を開いたら、左上の **歯車（種類の選択）→「ウェブアプリ」**を選んでください。デプロイ後に表示される **「ウェブアプリ URL」（.../exec で終わる URL）**をコピーします。既にデプロイ済みで URL を確認したい場合は、**「デプロイ → デプロイを管理」**から確認できます。

### Q. 画像を追加しようとするとポップアップがブロックされます

ローカル画像・Google ドライブ画像の利用には Google の認証が必要です。ボタンをクリックした直後に認証ポップアップが開くため、ブラウザでポップアップを**許可**してください。

### Q. Discord のテスト送信が失敗します

- Webhook URL の形式が正しいか（`https://discord.com/api/webhooks/...`）確認します。
- 先に GAS 連携が完了しているか確認します。
- GAS バックエンドが最新版でデプロイされているか確認します。

### Q. Bluesky にログインできません

Bluesky では通常のログインパスワードではなく、**App Password**（アプリパスワード）を使用します。Bluesky の設定からアプリパスワードを発行して登録してください。

### Q. Threads の認可が反映されません

Threads はアカウント登録後に **認可（Authorize）** の手順が必要です。認可画面で対象アカウントを許可し、コールバックが完了しているか確認してください。認可が切れた場合は再度認可してください。

### Q. 文字数の上限が Threads と Bluesky で違うのはなぜ？

数え方が異なるためです。**Threads は文字数（コードポイント）**、**Bluesky は書記素（grapheme）**でカウントします。絵文字や結合文字を含む場合、見た目の文字数と内部のカウントが異なることがあります。

### Q. クロスポストとは？

投稿作成画面で複数のアカウント（Bluesky / Threads をまたいでも可）を選択すると、同じ内容を一度に複数アカウントへ投稿できます。これをクロスポストと呼びます。
