# 初期セットアップ

アカウントを作成し、バックエンド（Google スプレッドシート）を接続するまでの手順です。テンプレートのコピーはボタン操作、デプロイだけを数クリックで行い、残り（シート作成・本人確認コード・URL 取得）は自動です。

:::tip 順番のコツ
**先にデプロイ → シートを再読み込み → メニュー実行**の順で進めてください。この順だと Google の認証（ポップアップ）が1回で済みます。デプロイが完了して初めて、シートメニューに「セットアップ」が表示されます。
:::

## 1. アカウント作成・サインイン

1. サインアップ画面でメールアドレスとパスワードを入力してアカウントを作成します。
2. 登録済みの場合はサインイン画面からログインします。
3. パスワードを忘れた場合は「パスワードを忘れた方」からリセットできます。

![サインイン画面](/img/screenshots/signin.png)

## 2. テンプレートをコピーする

アプリの **プロフィール → API 設定** を開き、上部の「初回セットアップ」にある **「テンプレートを Google ドライブにコピー」ボタン**を押します。Google の「コピーを作成」画面が開くので、そのまま作成します（**Google にサインインした状態**で操作してください）。スクリプトも一緒に複製され、コピーしたシートが自動で開きます。

## 3. ウェブアプリとしてデプロイする

コピーしたシートで、次を行います。

1. シートメニューの **「拡張機能 → Apps Script」** を開く。
2. スクリプトエディタ右上の **「デプロイ → 新しいデプロイ」** をクリック。
3. **「種類の選択（歯車）→ ウェブアプリ」** を選択。
4. **「デプロイ」→「アクセスを承認」** → Google の確認画面で **「すべて選択」→「続行」** で許可。
5. 表示された **「ウェブアプリ URL」**（`https://script.google.com/macros/s/.../exec`）をコピー。

:::info
この「アクセスを承認」が唯一の認証操作です。先にデプロイしておくことで、後のメニュー実行では認証ポップアップは出ません。
:::

## 4. セットアップを実行して連携する

1. スプレッドシートのタブに戻り、**ページを再読み込み**します（メニューが更新され、「セットアップ」が出るようになります）。
2. メニュー **「Autopost 連携」→「セットアップ（URL・本人確認コード）」** を実行。
3. ダイアログに、**ウェブアプリ URL（自動取得）**と**本人確認コード**が表示されます（それぞれコピーボタン付き）。デプロイ手順のチェックリストも確認できます。

![「Autopost 連携」メニュー](/img/screenshots/gas-menu.png)

4. アプリの **プロフィール → API 設定**に次を入力して保存します。
   - **Google Sheets URL** … ダイアログの **ウェブアプリ URL**（※ラベルは「Google Sheets URL」ですが、入れるのはこの URL です）
   - **GAS 本人確認コード** … ダイアログの **本人確認コード**

![API 設定（GAS 連携）](/img/screenshots/gas-setup.png)

:::caution
本人確認コードには有効期限があります（約 10 分）。期限が切れた場合は、メニューの「セットアップ（URL・本人確認コード）」を再実行して新しいコードを取得してください。
:::

## 5. バックエンドを更新する

バックエンドに更新があった場合の手順です。メニュー **「Autopost 連携」→「更新手順を表示」** でも同じ案内が出ます。**ウェブアプリ URL は変わらない**ため、アプリ側の再設定は不要です。

1. アプリの **プロフィール → API 設定**の **「GASスクリプト（code.js）を手動でダウンロード」**から最新コードを取得。
2. **「拡張機能 → Apps Script」**で既存コードを全て消し、貼り付けて保存。
3. **「デプロイ」→「デプロイを管理」→ 対象デプロイの編集（鉛筆）→ バージョン「新バージョン」→「デプロイ」**。

:::tip 権限エラーが出たら
「シートや Google ドライブへのアクセス権限がありません」と表示された場合は、スプレッドシートの **「Autopost 連携」メニュー**から権限の再承認をやり直してください。
:::

連携が完了したら、次は「[SNS アカウントを連携する](./connect-accounts.md)」に進みます。
