# 投稿を作成する

投稿の作成は、各アカウントの投稿画面や投稿一覧の **「新規投稿作成」** から開く投稿作成画面（コンポーザー）で行います。

![投稿作成画面](/img/screenshots/composer.png)

## 投稿先アカウントを選ぶ

投稿先は、チェックボックス付きのドロップダウンから選択します。複数アカウントを選ぶと、同じ内容をまとめて投稿（クロスポスト）できます。Bluesky と Threads をまたいで選択することも可能です。

## 本文を入力する

- 本文はテキストエリアに入力します。
- **絵文字ボタン**から絵文字を挿入できます。
- **文字数カウント**が表示されます。数え方はプラットフォームで異なります。
  - **Threads**: 文字数（コードポイント）
  - **Bluesky**: 書記素（grapheme）
- 上限を超えると警告が表示され、投稿できません。

## 画像を添付する

1 セグメントあたり最大 **4 枚**の画像を添付できます。追加方法は 2 通りです。

- **ローカルから選択** — 📷 ボタンからパソコン内の画像を選択します。
- **Google ドライブから選択** — Drive ボタンから、あなたの Google ドライブ上の画像を選択します。

添付した画像はドラッグ等で**並び替え**できます。画像はあなたの Google ドライブに保存され、投稿時に公開リンクとして使用されます。

:::info Google 連携について
ローカル画像も一度あなたの Google ドライブにアップロードしてから投稿します。初回は Google の認証（アクセス許可）が必要です。ボタンをクリックした直後に認証ポップアップが開きます（ポップアップブロックを許可してください）。
:::

## スレッド（連投）にする

セグメントを追加すると、複数の投稿を親 → 子の順につなげた**スレッド連投**を作成できます。各セグメントに個別の本文・画像を設定できます。

## プレビューと下書き保存

- **プレビュー**ボタンで、投稿の見え方を確認できます。
- **下書き保存**で、作成中の内容をブラウザに一時保存できます。次回コンポーザーを開いたときに復元されます。

## 予約日時を設定する

投稿ごとに予約日時を設定できます。

- **予約日時を設定した投稿** … 自動投稿の対象になり、その時刻以降に投稿されます。
- **予約日時を空にした投稿** … 「予約なし」として扱われ、**自動投稿されません**（下書きとして保管されます）。

:::tip
たくさんの投稿の予約時刻をまとめて割り振りたい場合は、投稿一覧の **「投稿間隔の配分」** が便利です。詳しくは「[投稿を管理する](./manage-posts.md#投稿間隔の配分)」を参照してください。
:::

作成した投稿は「[投稿を管理する](./manage-posts.md)」で確認・編集できます。
