# 自動投稿を稼働させる

自動投稿は、画面上部（ヘッダ）の **時計アイコン**から操作します。どのページからでも操作できます。

![ヘッダの自動投稿コントロール](/img/screenshots/auto-post-header.png)

## ON / OFF と間隔の設定

1. ヘッダの時計アイコンをクリックすると、設定パネルが開きます。
2. **投稿間隔**を選びます（1 / 5 / 10 / 15 / 30 分）。
3. **自動投稿スイッチ**を ON にすると、バックエンドに投稿トリガーが作成されます。
4. トリガーは指定した間隔で動作し、**予約時刻の来た投稿**を順番に投稿します。

アイコンは、自動投稿が ON のとき緑色に点灯します。ON 中に間隔を変更すると、トリガーは自動的に作り直されます。

## 動作の仕組み

- 予約時刻の来た投稿を、**親 → 子の順**（スレッドは親が投稿されてから子）で処理します。
- **予約日時が設定されていない投稿は投稿されません**（「予約なし」として保管されます）。
- スレッドの親がまだ投稿されていない場合、子は自動的に待機し、親の投稿後に続けて投稿されます。
- 対象の投稿がすべて処理されると、トリガーは自動的に停止（削除）されます。

:::caution
自動投稿を機能させるには、GAS バックエンドが最新版でデプロイされている必要があります。連携がうまく動かない場合は、スプレッドシート側の再デプロイ・再承認を確認してください。
:::

## エンゲージメント更新（1 日 1 回）

同じ設定パネルの下段に、**エンゲージメント更新**のスイッチがあります。ON にすると、投稿済みの投稿に付いた**いいね・返信・リポスト・引用**などの数値が、**1 日 1 回**自動で更新されます。更新された数値は投稿一覧の「投稿済み」タブに表示されます。

:::info 反映は最大 24 時間後です
実行時刻は Google 側が決めるため、スイッチを ON にした直後には数値は入りません。**翌日に確認**してください。すぐに更新する手動ボタンは用意していません（投稿数が多いと数分かかり、画面が待たされてしまうためです）。
:::

- 数値が **0 のまま**の場合、まだ 1 回目の更新が走っていない可能性があります。1 日待ってから確認してください。
- **Bluesky の「表示」「シェア」は取得できません**（Bluesky 側が公開していないため）。投稿一覧でも Threads の投稿にのみ表示されます。
- スイッチを OFF にすると更新が止まります。それまでに取得済みの数値はそのまま残ります。
- 自動投稿スイッチとは独立しています。自動投稿が OFF でも、エンゲージメント更新だけを ON にできます。

## 投稿結果を知る

投稿の結果は次の方法で確認できます。

- **アクティビティ画面** … 統計とエラー一覧を確認できます（「[アクティビティを見る](./activity.md)」）。
- **Discord 通知** … 投稿の成功・失敗を Discord に通知できます（「[Discord に通知する](./notifications.md)」）。
