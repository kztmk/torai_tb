# 投稿を管理する

投稿一覧は「予約」「投稿済み」「エラー」の 3 つのタブで構成されます。行のチェックボックスで複数選択すると、上部のアイコンツールバーで一括操作ができます。

![投稿一覧（予約タブ）](/img/screenshots/post-list.png)

## 予約タブ

これから投稿される（または下書きの）投稿の一覧です。

### 上部ツールバー（アイコン）

チェックで行を選択すると、上部にアイコンボタンが表示されます。各アイコンにマウスを乗せると説明が出ます。

| アイコン | 機能 |
| --- | --- |
| 新規投稿作成 | 投稿作成画面を開きます。 |
| AI で一括作成 | キーワードから複数の投稿の下書きを一括生成します（下記）。 |
| 一括削除 | 選択した投稿をまとめて削除します。 |
| 投稿間隔の配分 | 選択した投稿に予約日時を順に割り当てます（下記）。 |
| 予約クリア | 選択した投稿の予約日時を空にします（＝予約なし）。 |
| スレッド作成 | 選択した投稿を表示順にスレッド連投化します。 |

### 行ごとの操作

各行の先頭には **編集** / **削除** ボタンと **スレッドメニュー**があります。

- **編集** — 本文・画像・予約日時を修正できます。
- **削除** — その投稿を削除します。
- **スレッドメニュー** — 「スレッドから外す」（その投稿だけをスレッドから抜く）／「スレッド全解除」（スレッド全体を個別投稿に戻す）ができます。

### 投稿間隔の配分

複数の投稿を選択して「投稿間隔の配分」を開き、**開始日・終了日・開始時刻・終了時刻・間隔**を指定すると、選択した投稿に予約日時が順番に割り当てられます。まとめて予約したいときに使います。

:::note
この機能は自動投稿トリガーとは無関係です。あくまで各投稿の「予約日時」を一括設定するものです。
:::

![投稿間隔の配分](/img/screenshots/distribute.png)

### AI で一括作成

キーワードを入力すると、AI が複数の投稿案を生成します。生成された案はチェックボックスで採用を選べ、その場で編集もできます。採用した案が投稿一覧に追加されます。

:::info
AI 生成を使うには、**プロフィール → API 設定**で AI（OpenAI / Gemini / Anthropic）の API キーを登録しておく必要があります。
:::

## 投稿済みタブ

投稿が完了したものの一覧です。エンゲージメント（views / likes / replies / reposts / quotes / shares）や、投稿へのリンクを確認できます。

- **Bluesky** … 投稿 ID（AT URI）から投稿ページの URL を組み立ててリンク表示します。「表示」「シェア」は Bluesky が公開していないため取得できず、Threads の投稿にのみ表示されます。
- **Threads** … リンクをクリックすると、その投稿のパーマリンクを取得して新しいタブで開きます。

![投稿済みタブ](/img/screenshots/posted-list.png)

:::info エンゲージメントの数値が 0 のとき
数値の更新は **1 日 1 回**で、ヘッダの時計アイコンにある**エンゲージメント更新スイッチが ON のときだけ**動きます。数値が 0 のまま・「最終更新」が空欄のままの場合は、スイッチが ON か確認し、ON にした直後であれば 1 日待ってから見直してください。詳しくは「[自動投稿を稼働させる](./auto-posting.md)」を参照してください。
:::

## エラータブ

投稿に失敗したものと、その原因（エラー内容）を確認できます。原因を修正して予約し直すと、次回以降の自動投稿で再度投稿されます。

投稿の準備ができたら、「[自動投稿を稼働させる](./auto-posting.md)」に進みます。
