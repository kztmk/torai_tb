# Create posts

You create posts in the composer, which opens from **"New post"** on each account's posting screen or from the post list.

![Composer](/img/screenshots/composer.png)

## Choose target accounts

Select target accounts from the checkbox dropdown. If you select multiple accounts, you can publish the same content together (cross-posting). You can even select across Bluesky and Threads.

## Write the body

- Enter the body in the text area.
- Insert emoji from the **emoji button**.
- A **character count** is shown. The counting differs by platform:
  - **Threads**: characters (code points)
  - **Bluesky**: graphemes
- If you exceed the limit, a warning appears and you cannot post.

## Attach images

You can attach up to **4 images** per segment. There are two ways to add them:

- **Choose from local** — select an image from your computer via the 📷 button.
- **Choose from Google Drive** — select an image from your Google Drive via the Drive button.

Attached images can be **reordered** (e.g. by dragging). Images are stored in your Google Drive and used as public links when posting.

:::info About Google integration
Local images are also uploaded to your Google Drive before posting. The first time, Google authentication (access permission) is required. An auth popup opens immediately after you click the button (please allow popups).
:::

## Make it a thread

By adding segments, you can create a **thread** where multiple posts are chained in parent → child order. Each segment can have its own body and images.

## Preview and save draft

- Use the **Preview** button to check how the post will look.
- Use **Save draft** to temporarily save your work in the browser. It is restored the next time you open the composer.

## Set a scheduled time

You can set a scheduled time per post.

- **Posts with a scheduled time** … become targets for auto-posting and are published at or after that time.
- **Posts with an empty scheduled time** … are treated as "not scheduled" and are **not auto-posted** (they are kept as drafts).

:::tip
To assign scheduled times to many posts at once, the **"Distribute scheduled times"** feature in the post list is convenient. See "[Manage posts](./manage-posts.md#distribute-scheduled-times)".
:::

You can review and edit created posts in "[Manage posts](./manage-posts.md)".
