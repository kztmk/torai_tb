# View the Activity page

The **Activity** (dashboard) in the left menu lets you check an overview of your posting status and any errors.

![Activity page](/img/screenshots/activity.png)

## What is shown

- **Stat cards** … an overview such as the number of registered accounts and post status.
- **Error list** … recent posting errors and their details.

If errors appear, review the details and fix the relevant posts in the Errors tab or Scheduled tab of "[Manage posts](./manage-posts.md)". If you reschedule them, they are published again on a later auto-posting run.

## Navigating to account management / posting screens

From the buttons on the Activity page or the **SNS** tree in the left menu, you can navigate to each platform's account management and posting screens.
