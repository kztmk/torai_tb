# API settings (AI & Discord)

In **Profile → API settings**, in addition to the GAS connection, you configure AI post generation and Discord notifications.

![API settings screen](/img/screenshots/api-settings.png)

## AI (bulk post generation) API keys

To use bulk AI post generation, register one of the following API keys.

| Provider | Purpose |
| --- | --- |
| OpenAI | Generation with ChatGPT-family models |
| Gemini | Generation with Google Gemini |
| Anthropic | Generation with Claude |

- Once you enter and save a key, **"Bulk AI generation"** in the post list becomes available.
- Gemini supports key format validation and a test run.

:::info
Issue API keys from each provider's console. Follow each service's pricing and terms of use.
:::

## Discord notifications

Settings to notify Discord of post results. See "[Notify Discord](./notifications.md)" for the steps.

## GAS connection

Settings to connect your Google Spreadsheet. See "[Getting Started](./getting-started.md)" for the steps.
